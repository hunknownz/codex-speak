# Codex 朗读助手需求文档

## 一句话需求

让 Codex 在回复完成后，自动朗读一段由 Codex 自己生成的、中文优先、儿童也能听懂、并能说明 Codex 具体做了什么的本地语音复述。

## 为什么要做

Codex 的回复经常包含代码、路径、命令和技术词，直接朗读会很生硬，也不适合孩子、初学者或想边听边操作的人。这个功能要把“给眼睛看的回答”变成“给耳朵听的回答”，并且尽量本地化、免费、保护隐私。

## 核心目标

- 自动朗读 Codex 回复的重点内容。
- 中文优先，英文技术词能自然处理。
- 不读代码块、日志、长路径、diff 和无意义符号。
- 儿童模式下使用短句、简单词和忠实复述，既好听懂，也不丢掉关键操作。
- TTS 本地离线运行，优先免费方案。
- 支持 macOS 和 Windows，普通电脑可运行。
- 支持给其他用户自动化安装、升级、卸载和自检。

## 非目标

- 第一阶段不做桌面宠物、角色动画或卡通人物。
- 第一阶段不依赖外部大模型 API。
- 第一阶段不追求声音克隆。
- 第一阶段不把 Plugin 作为必需组件。

## 目标用户

- 想让 Codex 回复自动读出来的开发者。
- 中文用户、低龄学习者、编程初学者。
- 需要无障碍朗读、边听边操作的人。
- 想做本地化 AI 工具演示和内容分享的人。

## MVP 范围

1. Codex 回复结束后自动触发 Hook。
2. Codex Skill 在回答中生成隐藏的朗读复述。
3. Hook 提取朗读复述；找不到时用规则清洗兜底。
4. 本地 TTS 生成音频并播放。
5. 支持开关、语速、最大朗读长度、儿童模式配置。
6. macOS 和 Windows 都有可行的播放路径。
7. 提供一键安装脚本或安装器，自动完成 Skill、Hook、TTS 引擎和模型部署。
8. 提供卸载和恢复能力，不破坏用户原有 Codex 配置。

## 安装部署需求

- 安装过程尽量少提问，普通用户可以按提示完成。
- 自动识别系统、CPU 架构、Codex 配置目录和可用播放器。
- 自动下载或安装合适的本地 TTS 引擎和中文模型。
- 安装前备份原有 Codex 配置，卸载时可以恢复。
- 支持升级，不重复安装、不覆盖用户自定义配置。
- 提供 `doctor` 自检命令，检查 Hook、Skill、模型、播放器是否正常。
- 安装失败时给出清楚错误原因和下一步操作。
- 发布给大众用户时，macOS 需要签名和公证，Windows 需要签名或可信分发渠道，减少安全警告。

## 成功标准

- 普通回复可以自动朗读。
- 朗读内容比原文短，且不包含代码和大段路径。
- 中文听感比系统自带 `say` 或 Windows 默认朗读更自然。
- 无网络时仍可工作。
- 低配机器可切换到轻量兜底声音。
- 新用户可以在 5 分钟内完成安装并听到第一段朗读。
- 卸载后 Codex 能恢复到安装前的可用状态。
