# Codex 朗读助手需求文档

## 一句话需求

让 Codex 在长任务中可播放少量进度提示，并在回复完成后通过本地 side-channel 自动朗读一段由 Codex 理解后生成的中文导览，帮助小朋友听懂 Codex 做了什么、结果是什么、下一步怎么继续。

## 为什么要做

Codex 的回复经常包含代码、路径、命令和技术词，直接朗读会很生硬，也不适合孩子、初学者或想边听边操作的人。这个功能要把“给眼睛看的回答”变成“给耳朵听的回答”，并且尽量本地化、免费、保护隐私。

## 核心目标

- 自动朗读 Codex 回复的重点内容。
- 支持“过程中少量进度提示，结束后完整导览”的朗读时机策略，详见 [朗读时机策略](speech-timing.md)。
- 中文优先，英文技术词能自然处理。
- 不读代码块、日志、长路径、diff 和无意义符号。
- 儿童模式下使用短句、简单词和行动导览，既好听懂，也能推动孩子继续使用 Codex。
- TTS 本地离线运行，优先免费方案。
- 支持 macOS 和 Windows，普通电脑可运行。
- 支持给其他用户自动化安装、升级、卸载和自检。
- 提供图形化控制面板，让普通用户可以点击开关、调语速、试听和停止朗读。

## 非目标

- 第一阶段不做桌面宠物、角色动画或卡通人物。
- 第一阶段不依赖外部大模型 API。
- 第一阶段不追求声音克隆。
- 第一阶段不依赖插件改写、隐藏或折叠 Chat Session 的渲染结果。

## 目标用户

- 想让 Codex 回复自动读出来的开发者。
- 中文用户、低龄学习者、编程初学者。
- 需要无障碍朗读、边听边操作的人。
- 想做本地化 AI 工具演示和内容分享的人。

## MVP 范围

1. Codex 回复结束后自动触发 Hook。
2. Codex Skill 让 Codex 理解完整任务，并生成适合小朋友听的朗读导览。
3. Plugin/MCP 优先把朗读导览写入本地 side-channel，并可触发少量非阻塞进度朗读。
4. Hook 优先消费 side-channel；找不到时读取 Skill 生成的短 Markdown `朗读导览`；再找不到才解析历史 HTML/Markdown 兼容协议或播放极保守短播报，不能把普通 final answer 当作主要朗读源。
5. 本地 TTS 生成音频并播放。
6. 支持开关、语速、最大朗读长度、儿童模式配置。
7. macOS 和 Windows 都有可行的播放路径。
8. 提供一键安装脚本或安装器，自动完成 Skill、Hook、TTS 引擎和模型部署。
9. 提供卸载和恢复能力，不破坏用户原有 Codex 配置。
10. 提供 Tauri 控制面板，用于儿童模式、语速、声音档位、试听、停止和自检。

## 安装部署需求

- 安装过程尽量少提问，普通用户可以按提示完成。
- 自动识别系统、CPU 架构、Codex 配置目录和可用播放器。
- 自动下载或安装合适的本地 TTS 引擎和中文模型。
- 安装前备份原有 Codex 配置，卸载时可以恢复。
- 支持升级，不重复安装、不覆盖用户自定义配置。
- 提供 `doctor` 自检命令，检查 Hook、Skill、模型、播放器是否正常。
- 安装失败时给出清楚错误原因和下一步操作。
- 发布给大众用户时，macOS 需要签名和公证，Windows 需要签名或可信分发渠道，减少安全警告。

## 成功标准

- 普通回复可以自动朗读。
- 长任务中可以听到少量自然进度提示，但不会逐字朗读流式聊天输出。
- 朗读内容比原文短，且不包含代码和大段路径。
- 中文听感比系统自带 `say` 或 Windows 默认朗读更自然。
- 常见英文技术词不会按字母生硬拼读；混在中文导览里的未知英文词、短语和编号会先变成中文提示；普通英文短语在系统兜底时也能用英文声音朗读。
- 无网络时仍可工作。
- 低配机器可切换到轻量兜底声音。
- 新用户可以在 5 分钟内完成安装并听到第一段朗读。
- 卸载后 Codex 能恢复到安装前的可用状态。
