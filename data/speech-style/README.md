# Speech Style Data

This directory tracks candidate sources and distilled principles for Codex Speak's child/adult speech style.

Do not paste large copyrighted passages here. Store source metadata, short paraphrased principles, and original examples created for this product.

Files:

- `source-candidates.jsonl`: candidate public sources, license status, use level, and risk notes.
- `distilled-principles.jsonl`: product-ready style principles distilled from reviewed sources.

Use levels:

- `rule_distillation`: safe to use as a source for general writing rules.
- `sample_reference`: may inspect small samples and create original examples.
- `research_only`: do not ingest into product data.
- `blocked`: do not use.
